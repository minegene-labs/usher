# Security policy

## Reporting a vulnerability

Please report it privately, not in a public issue: use GitHub's **Report a vulnerability** button on the repository's Security tab (private vulnerability reporting). Say what you found, how to reproduce it and which version (Settings → About shows it). Don't include real passwords, API keys or personal data.

You can expect an acknowledgement within a few days. A fix is merged as soon as it is ready and reaches every install with the next release, which is made soon after a security fix; its notes say what was fixed once people have had the chance to update.

## Supported versions

Only the latest release is supported. Usher installs nothing by itself unless the optional daily update is turned on, so keep your install on the latest release (Settings → About → Updates says when a newer one is out).

## What is in scope

How Usher protects accounts, sessions and the services behind it is described in [docs/security.md](docs/security.md), including the threat model.
